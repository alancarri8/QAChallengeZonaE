# QA Challenge

Repositorio que contiene un framework pruebas de UI realizado con **Cypress/JavaScript**, utilizando como reporteria **Mochawesome**, libreria FakerJs para utilización de datos y dotenv para variables de ambiente, aplicando **POM (page object model)**

## Requisitos previos para su uso

> npm - node.js

## Configuaración del proyecto

```
1 - Clonar repositorio: git clone https://github.com/alancarri8/QAChallengeZonaE.git
2 - Ingresar al directorio: cd QAChallengeZonaE
3 - Instalar dependencias: npm install
```

## Ejecuión de pruebas

```
Comando para ejecutar pruebas
npm run cy:run:test

```

## Archivos

```
Ubicación del reporte: cypress/reports/html/index.html

Las evidencias se almacenan en cypress/screenshots/

En la carpeta ChallengeDocs se encuentran realizados los puntos 1, 2,3 y 5

```
